SLIDE 14: CODE WALKTHROUGH (2 minutes)
================================================================================

SHOW KEY CODE SNIPPETS:

1. SMART CONTRACT - BUY FUNCTION:
```solidity
function buyTrademark(uint256 listingId) external payable nonReentrant {
    Listing storage listing = listings[listingId];
    require(listing.active, "Listing is not active");
    require(msg.value == listing.price, "Incorrect payment");
    
    // Calculate royalty and fees
    (address royaltyReceiver, uint256 royaltyAmount) = 
        trademarkNFT.royaltyInfo(listing.tokenId, listing.price);
    uint256 marketplaceFeeAmount = (listing.price * marketplaceFee) / 10000;
    uint256 sellerAmount = listing.price - royaltyAmount - marketplaceFeeAmount;
    
    // Transfer NFT
    trademarkNFT.safeTransferFrom(listing.seller, msg.sender, listing.tokenId);
    
    // Distribute payments
    payable(royaltyReceiver).transfer(royaltyAmount);
    payable(owner()).transfer(marketplaceFeeAmount);
    payable(listing.seller).transfer(sellerAmount);
    
    emit TrademarkSold(listingId, listing.tokenId, msg.sender, ...);
}
```

2. WEB3 INTEGRATION:
```typescript
const registerTrademark = async (data) => {
  // Upload to IPFS
  const ipfsHash = await uploadFilesToIPFS(data.files);
  
  // Get signer
  const signer = await provider.getSigner();
  const contract = new ethers.Contract(address, abi, signer);
  
  // Call smart contract
  const tx = await contract.registerTrademark(
    data.companyName,
    data.sloganText,
    data.registrationNumber,
    ipfsHash,
    data.category,
    royaltyBps,
    tokenURI
  );
  
  // Wait for confirmation
  const receipt = await tx.wait();
  const tokenId = extractTokenIdFromEvent(receipt);
  
  return tokenId;
};
```

3. WALLET INTEGRATION COMPLEXITY

4. STATE SYNCHRONIZATION
   Problem: Blockchain vs database consistency
   Solution: Event-driven updates, hybrid architecture

5. USER EXPERIENCE
   Problem: Web3 complexity for non-technical users
   Solution: Clear UI, helpful error messages, guided flows

6. TESTING BLOCKCHAIN INTERACTIONS
   Problem: Difficult to test on-chain operations
   Solution: Local Hardhat network, testnet deployment
